# TraRead マニュアル: テキスト入力・表示・操作

このドキュメントでは、TraReadのテキスト入力方法、表示機能、操作方法について説明します。
アプリ起動時には、虎のキャラクターが描かれたアプリアイコン（半透明）がプレースホルダーとして表示されます。

## 1. テキストの入力方法

TraReadでは、以下の3つの方法で英語テキストを読み込むことができます。

### 1.1 ドラッグ＆ドロップ

1. Finder などで `.txt` または `.pdf` ファイルを見つけます。
2. ファイルをTraReadウィンドウにドラッグ＆ドロップします。
3. テキストが自動的に読み込まれ、文章の読み上げが開始されます。

### 1.2 ファイルピッカー（ファイルを開く）

1. プレースホルダー画面の **「ファイルを開く...」** ボタンをクリックします。
2. ファイル選択ダイアログから `.txt` または `.pdf` ファイルを選択します。
3. **「開く」** をクリックすると、テキストが読み込まれます。

### 1.3 ⌘V（ペースト）入力

1. 任意のアプリケーションで英語テキストをコピーします（`⌘C`）。
2. TraReadウィンドウをクリックしてフォーカスします。
3. `⌘V` を押すと、クリップボードのテキストが読み込まれます。

## 2. サポートされるファイルタイプ

- `.txt`（プレーンテキストファイル）
- `.pdf`（Portable Document Format）

## 3. テキストの表示

テキストが読み込まれると、以下のように表示されます：

- **現在の文** — 画面中央に大きく太字で表示
- **日本語翻訳** — 現在の文の下にオレンジ色で表示
- **前の文** — 現在の文の上に薄い灰色で表示
- **次の文** — 現在の文の下に薄い灰色で表示
- **プログレスバー** — 全体の中での現在位置を表示（例：`3 / 12`）

## 4. 文章の操作

### 4.1 次の文に進む

以下の3つの方法で次の文に進むことができます：

1. **Enter キー** を押す
2. **画面の任意の場所をクリック**する
3. 中央下部の **再生ボタン（▶）をクリック**する

> **注意**: 画面タップや Enter キー、中央の再生ボタンによる進行は読み上げ完了後まで待機する必要がありますが、右側の **⏩ (Next/FFボタン)** は読み上げ中も常に使用可能です。クリックすると即座に次の文へ移動し、再生が開始されます。

### 4.2 前後移動

- **⏪ ボタン**: 前の文に戻ります
- **⏩ ボタン**: 次の文に進みます

### 4.3 コピー機能

1. 右下の **コピーボタン（📋）** をクリックします。
2. **これまで読み上げ・翻訳されたすべての文章ペア** がクリップボードにコピーされます。
3. 「コピーしました」のメッセージが一時的に表示されます。

コピーされるテキストの形式：
```
This is the English sentence.
これは英語の文です。
```

## 5. エラー処理

- サポートされていないファイルタイプを読み込むと、エラーメッセージが表示されます。
- ファイルアクセスに問題がある場合（セキュリティ制限など）、エラーメッセージが表示されます。
- ⌘V で空のテキストをペーストした場合は何も起こりません。
