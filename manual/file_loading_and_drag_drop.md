# ファイル読み込みとドラッグ＆ドロップ機能

このドキュメントでは、TraReadのファイル読み込みおよびドラッグ＆ドロップ機能の使用方法について説明します。

## 1. 「ファイルを開く...」ボタンによるファイルの読み込み

専用の「ファイルを開く...」ボタンを使用して、`.txt`（プレーンテキスト）および`.pdf`（Portable Document Format）ファイルを開くことができます。

### 使用方法：
1.  アプリケーションウィンドウにある**「ファイルを開く...」ボタン**をクリックします。
2.  標準のファイル選択ダイアログ（`NSOpenPanel`）が表示されます。
3.  システム上の目的の`.txt`または`.pdf`ファイルに移動します。
4.  ファイルを選択し、**「開く」**をクリックします。
5.  選択したファイルの内容が`TextEditor`に読み込まれます。
6.  アプリケーションは、読み込まれたテキストを自動的に処理し、文章に区切り、最初の文章の読み上げと翻訳プロセスを開始します。
7.  「次へ」および「前へ」ボタンを使用して、読み込まれたドキュメントの文章間を移動します。

## 2. ドラッグ＆ドロップによるファイルの読み込み

`.txt`および`.pdf`ファイルをTraReadアプリケーションウィンドウに直接ドラッグ＆ドロップすることによっても、ファイルを読み込むことができます。

### 使用方法：
1.  Finder（または任意のファイルブラウザ）で`.txt`または`.pdf`ファイルを特定します。
2.  ファイルをその場所からドラッグし、TraReadアプリケーションウィンドウの任意の場所にドロップします。
3.  アプリケーションはドロップされたファイルを検出し、その内容を読み込み（PDFの場合はテキストを抽出）、`TextEditor`に入力します。
4.  その後、アプリケーションは読み込まれたテキストを自動的に処理し、文章に区切り、最初の文章の読み上げと翻訳プロセスを開始します。
5.  「次へ」および「前へ」ボタンを使用して、読み込まれたドキュメントの文章間を移動します。

## 3. サポートされるファイルタイプ
-   `.txt`（プレーンテキストファイル）
-   `.pdf`（ポータブルドキュメント形式ファイル）

## 4. エラー処理
-   サポートされていないファイルタイプを読み込もうとすると、メインの表示領域（文章が表示される場所）にエラーメッセージが表示され、ファイルは処理されません。
-   ドロップされたファイルへのアクセスに問題がある場合（例：セキュリティ制限のため）、エラーメッセージが表示されます。

## 5. 既存機能との連携
-   ファイルから読み込まれたテキスト（「ファイルを開く...」またはドラッグ＆ドロップのいずれか）は、`TextEditor`内の既存のテキストを置き換えます。
-   読み込まれたテキストは、手動で入力されたテキストと同じ文章区切り、翻訳、および音声合成ロジックによって処理されます。
-   「前へ」および「次へ」ナビゲーションボタンは、読み込まれたファイルの内容に対しても同様に機能します。
